# キホンのキ 仕様

基本情報技術者試験を、パス型レッスンで学ぶ個人用Webアプリ。非公開で、ローカルで動かす。
今回は「ガワ」が目的で、問題は `src/content/units/*.json` を足すだけで増やせること。

名前・キャラクター・イラストはオリジナルにする。特定サービスのロゴ、キャラクター、名称は使わない。
配色と画面構成は、大手語学学習アプリの定番パターン（下記の色）に近づける。

## 技術構成

- Vite + React + TypeScript（SPA）。ルーターは入れず、画面は state で切り替える
- CSS は素の CSS（`src/styles/*.css` か単一の `src/styles.css`）。色は `:root` の CSS 変数
- フォント: `@fontsource/m-plus-rounded-1c`（500 / 700 / 800）
- 進捗は localStorage（キー `kihon-no-ki:v1`）。サーバーなし
- テスト: Vitest（`src/lib` の純粋ロジックのみ）
- `vite.config.ts` の `base` は `./`
- 依存はこれ以外に増やさない

## コンテンツ形式

`src/content/units/*.json` を `import.meta.glob('./units/*.json', { eager: true })` で読む。`_` で始まるファイルは読まない。ユニットは `order` の昇順に並べる。

```ts
type Unit = {
  id: string;
  order: number;
  title: string;
  description?: string;
  color?: 'green' | 'blue' | 'purple' | 'orange' | 'red' | 'gold'; // 省略時は順に割り当て
  lessons: Lesson[];
};
type Lesson = { id: string; title: string; questions: Question[] };

type Base = { prompt: string; code?: string; explanation?: string };
type Question = Base & (
  | { type: 'choice'; choices: string[]; answer: string }   // answer は choices の値。表示時にシャッフル
  | { type: 'truefalse'; answer: boolean }                  // 「正しい / 誤り」の2択
  | { type: 'order'; answer: string[]; distractors?: string[] } // チップをタップして順に並べる
  | { type: 'match'; pairs: [string, string][] }            // 左右を組み合わせる
);
```

- `code` は等幅のコードブロックで表示する（疑似言語問題用）
- 問題の識別子は `lesson.id` と `prompt` のハッシュから自動生成する（JSON に id を書かせない）
- `src/content/loader.ts` で検証する。id の重複、必須項目の欠落、`answer` が `choices` にない等を検出したら、その問題やファイルだけ除外し、ホーム上部に赤い警告バナーで「ファイル名と理由」を表示する。アプリは落とさない

## 調整値

`src/config.ts` に集約する: アプリ名、キャラ名、`maxHearts: 5`、`heartRegenMinutes: 30`、`xpLesson: 10`、`xpPerfectBonus: 5`、`xpReplay: 5`、`xpReview: 5`、`dailyGoalXp: 20`、`reviewSessionSize: 10`。

## 画面

### レイアウト

- 幅 1024px 以上: 左サイドバー（幅 256px。ロゴとナビ）、中央（最大 600px）、右パネル（幅 340px）
- 700〜1023px: 左サイドバーと中央のみ
- 700px 未満: 上部に統計バー、下部にタブバー。横スクロールを出さない
- ナビ: 学ぶ / 復習 / 記録（アイコンは自作のインライン SVG）
- 統計: 連続日数（オレンジ）、合計 XP（金）、ハート（赤）
- 右パネル: 統計、今日の目標 XP の進捗カード

### 学ぶ（ホーム）

- ユニットごとに色付きバナー（「ユニット N」「タイトル」「説明」）。スクロール中は現在のユニットのバナーを `position: sticky` で上に固定
- その下にレッスンの丸ノードを縦に並べ、サイン波で左右にずらす（ジグザグ）
- ノードは 3 状態: 完了（ユニット色＋チェック）、現在（ユニット色＋周囲に進捗リング＋上に跳ねる「はじめる」吹き出し）、ロック（グレー＋鍵）
- 解放判定: 全レッスンを順に並べ、最初の未完了が「現在」、それより後がロック。完了はレッスン ID で保存するので、後から問題やレッスンを足しても壊れない
- ノードをタップするとポップオーバーでレッスン名、問題数、ボタン（「はじめる」または「もう一度」）を表示。ロックは「前のレッスンを完了しよう」
- 途中にキャラクターを置く

### レッスン

- 上部: 閉じる ×、進捗バー（緑）、残りハート
- 中央: 問題（下記 4 形式）
- 下部: 「チェック」ボタン。未回答は無効（グレー）
- 回答後: 下部が正解（緑パネル）または不正解（赤パネル）に変わり、見出し、正答、`explanation`、「つづける」ボタンを表示
- 不正解: ハート -1、その問題をキューの末尾に戻す。全問正解するまで続ける
- ハート 0: モーダルで「ハートがなくなりました」、次の回復までの時間、「全回復する」（無料）と「やめる」
- × で中断するときは確認モーダルを出す
- キーボード: 1〜9 で選択、Enter でチェック / つづける

形式別の UI:

- `choice`: 縦並びのカード。選択中は青。番号バッジ付き
- `truefalse`: 「正しい」「誤り」の 2 カードを横並び
- `order`: 上に回答欄（下線の行）、下にチップ群。タップで移動し、回答欄のチップをタップで戻す。チップは `answer` + `distractors` をシャッフル
- `match`: 左右 2 列のカード。左右を 1 つずつ選ぶ。合えば緑で無効化、違えば赤く揺らす。全部合うと自動で正解パネル。誤タップでハートは減らさず、正答率の分母と誤答数にだけ数える

### 完了画面

キャラクター（喜び）、紙吹雪（CSS のみ）、「レッスン完了！」、3 枚のカード（獲得 XP / 正答率 / かかった時間）、「つづける」。

XP: 初回は `xpLesson`、誤答 0 なら `xpPerfectBonus` を加算。再挑戦は `xpReplay`。

### 復習

レッスンで間違えた問題を保存する（`match` は保存しない）。「復習する」で最大 `reviewSessionSize` 問。ハートは減らない。正解した問題はリストから消す。完了で `xpReview`。0 件ならキャラクターと「復習する問題はありません」を表示。

### 記録

合計 XP、連続日数、完了レッスン数 / 全レッスン数、直近 7 日の XP 棒グラフ（CSS のみ、緑）、ユニット別の進捗バー、「進捗をリセット」（確認モーダル付き）。

## ロジック（`src/lib`、純粋関数でテストを書く）

- 連続日数: ローカル日付で判定。同日は維持、前日なら +1、それ以外は 1 にリセット。表示時、最終学習日が一昨日以前なら 0
- ハート: `heartRegenMinutes` ごとに 1 回復し上限は `maxHearts`。保存は「ハート数」と「最後の回復基準時刻」
- 解放判定、XP 計算、キュー操作（不正解で末尾へ）、コンテンツ検証
- localStorage の読み書きは try/catch で囲み、壊れていたら初期状態にする。日付と時刻は引数で渡せるようにしてテストする

## キャラクター

`src/components/Mascot.tsx` にインライン SVG で自作する。ピンの生えた丸いマイクロチップの形で、目と口があるオリジナルのキャラ。名前は「チップ」。`mood` に `normal` / `happy` / `sad`。鳥や動物にしない。

## その他

- アニメーションは `prefers-reduced-motion` で止める
- ボタンは `button` 要素、フォーカスリングあり、タップ領域 44px 以上
- UI 文言はすべて日本語
- `README.md`（日本語）: 起動方法、問題の足し方（4 形式の例）、調整値の場所
- `src/content/units/` の既存 JSON と `docs/spec.md` は変更しない。`_template.json` も含め、ここにあるものをそのまま使う
